# House Age Prediction (California Housing)

Predicts the age of houses from location, income, population and room data.

## Results
| Model | R² | MAE |
|---|---|---|
| Linear Regression | 0.20 | 9.2 years |
| Random Forest | 0.60 | 6.0 years |

## Key findings
- Random Forest performed best.
- Location (longitude and latitude) was the strongest predictor.
